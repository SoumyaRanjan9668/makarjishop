MAKAR JI — HANDCRAFTED TOOL WORKSHOP IMAGES GUIDE
======================================================================

To display actual workshop photos for any of the 13 handcrafted tools,
simply place JPG or PNG image files in this folder with the exact filenames
listed below:

1.  Paniki:           paniki.jpg
2.  Korana:           korana.jpg
3.  Hand Korana:      hand-korana.jpg
4.  Kuradi:           kuradi.jpg
5.  Katuri:           katuri.jpg
6.  Daab:             daab.jpg
7.  Kodal:            kodal.jpg
8.  Churi:            churi.jpg
9.  Kulhadi:          kulhadi.jpg
10. Hasua:            hasua.jpg
11. Khurpi:           khurpi.jpg
12. Shovel / Spade:   shovel-spade.jpg
13. Gaiti:            gaiti.jpg

----------------------------------------------------------------------
RECOMMENDED IMAGE SPECIFICATIONS:
----------------------------------------------------------------------
- Format: JPG, WebP, or PNG
- Aspect Ratio: 4:3 (landscape) or 1:1 (square)
- Recommended Resolution: 1200 x 900 px (or minimum 800 x 600 px)
- Style: Real workshop photos of the tool on an anvil, wooden workbench,
  or forge background.

----------------------------------------------------------------------
FALLBACK BEHAVIOR:
----------------------------------------------------------------------
If any photo is not present in this folder, the website automatically
and gracefully displays an authentic handcrafted blacksmith badge with
the tool's name and hindi title, indicating to visitors that actual
workshop photos are being updated directly from the forge.
